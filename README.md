# malang_pet — 말랑이 키우기

배경화면에 귀여운 캐릭터들이 오버레이로 다마고치 처럼 움직이는 프로그램.

다마고치처럼 하찮고 말랑한 도트 "말랑이"를 키우는 바탕화면 펫 (Electron).
말랑이들은 작업표시줄 위를 돌아다니고, 말랑이가 없는 곳은 클릭이 그대로 바탕화면으로 통과해요.

## 실행

```
npm install
npm start
```

## exe 만들기

```
npm run dist
```

`dist` 폴더에 두 가지가 만들어져요.

- `MalangPet-Setup-<버전>.exe` — 설치판. 더블클릭하면 설치되고 바탕화면·시작 메뉴에 `말랑이 키우기` 아이콘이 생겨요
- `MalangPet-<버전>.exe` — 설치 없이 더블클릭으로 바로 실행되는 단일 파일

## 돌보는 법

- **말랑이 클릭** — 머리 위에 돌봄 카드가 떠요 (밥 / 놀기 / 씻기 / 재우기 / 약)
- **집어 던지기** — 드래그해서 들었다 놓으면 통통 튀어요 (너무 세게 던지면 어지러워해요)
- **응가 치우기** — 바닥의 응가를 클릭하거나 씻기. 빗자루가 슥슥 쓸어 가요
- **꼬질꼬질** — 오래 안 씻기면 몸에 얼룩이 생기고, 냄새가 나고, 파리가 꼬여요. 말랑이 위에서 마우스를 좌우로 문지르면 뽀득뽀득 씻겨요
- **켜기 / 끄기** — 설치판은 바탕화면의 `말랑이 키우기` 아이콘으로 켜요 (숨겨 뒀을 때 누르면 다시 나타나요). 끌 때는 집 창의 `끄기`나 트레이 메뉴의 `종료`
- **재우기** — 말랑이가 말랑이네 현관으로 걸어 들어가 침대에서 자요. 집 창에서 자는 말랑이를 누르면 깨울 수 있어요
- **말랑이네(오른쪽 아래 새싹 말풍선) 클릭** — 작은 집 창이 열려요. 방 안의 말랑이들을 보고, 입양 / 모두 부르기 / 테마 바꾸기
- **창밖** — 지금 시간대와 실제 날씨(맑음·흐림·비·눈·천둥번개·안개)가 보이고, 밤엔 오늘 뜨는 달 모양이 떠요. 집 창의 `지역`에서 도시를 바꿀 수 있어요 (날씨: [Open-Meteo](https://open-meteo.com))
- **집중 모드** — 집 창이나 트레이 메뉴에서 켜면 내 말랑이 머리 위에 `집중 중` 말풍선이 뜨고, 친구 목록에도 집중 중으로 보여요
- **친구 · 쪽지** — 친구 코드로 연결하면 말랑이가 쪽지·사진을 들고 친구 바탕화면에 놀러 가요. 대화창에서 주고받은 말을 보고, `흔들기`로 친구 말랑이를 흔들 수 있어요 (둘 다 켜져 있을 때만)
- **감정은 구름 말풍선**, 원하는 게 있으면 **네모 말풍선**으로 말해요
- **트레이 아이콘 우클릭** — 입양, 부르기, 테마, 항상 위에 표시, 숨기기, 종료
- 알은 30초 뒤에 깨어나고, 1일 뒤 어린이, 3일 뒤 어른으로 자라요
- 배고프거나 더러운 상태가 오래가면 아파요. 약을 먹여 주세요
- 프로그램을 꺼 둔 동안에도 시간이 흘러요. 트레이로 숨겨 뒀을 때 돌봄이 필요하면 윈도우 알림이 와요
- 최대 6마리까지 함께 살 수 있어요
