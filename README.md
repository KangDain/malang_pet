# malang_pet — 말랑이 키우기

배경화면에 귀여운 캐릭터들이 오버레이로 다마고치 처럼 움직이는 프로그램.

다마고치처럼 하찮고 말랑한 도트 "말랑이"를 키우는 바탕화면 펫 (Electron).
말랑이들은 작업표시줄 위를 돌아다니고, 말랑이가 없는 곳은 클릭이 그대로 바탕화면으로 통과해요.

## 실행

```
npm install
npm start
```

## exe 만들기

```
npm run dist
```

`dist\MalangPet-<버전>.exe` 가 만들어져요. 설치 없이 더블클릭으로 바로 실행되는 단일 파일이에요.

## 돌보는 법

- **말랑이 클릭** — 머리 위에 돌봄 카드가 떠요 (밥 / 놀기 / 씻기 / 재우기 / 약)
- **집어 던지기** — 드래그해서 들었다 놓으면 통통 튀어요 (너무 세게 던지면 어지러워해요)
- **응가 치우기** — 바닥의 응가를 클릭하거나 씻기
- **말랑이네(오른쪽 아래 새싹 말풍선) 클릭** — 작은 집 창이 열려요. 방 안의 말랑이들을 보고, 입양 / 모두 부르기 / 테마 바꾸기
- **감정은 구름 말풍선**, 원하는 게 있으면 **네모 말풍선**으로 말해요
- **트레이 아이콘 우클릭** — 입양, 부르기, 테마, 항상 위에 표시, 숨기기, 종료
- 알은 30초 뒤에 깨어나고, 1일 뒤 어린이, 3일 뒤 어른으로 자라요
- 배고프거나 더러운 상태가 오래가면 아파요. 약을 먹여 주세요
- 프로그램을 꺼 둔 동안에도 시간이 흘러요. 트레이로 숨겨 뒀을 때 돌봄이 필요하면 윈도우 알림이 와요
- 최대 6마리까지 함께 살 수 있어요

## 디자인

- 색은 `color.txt.txt`의 라이트/다크 팔레트를 `renderer.js`의 `THEMES`에 그대로 옮겨 썼어요. 기본은 Windows 테마를 따라가요.
- 글꼴: [갈무리](https://github.com/quiple/galmuri) (SIL OFL 1.1, `fonts/OFL.md`)

세이브 파일: `%APPDATA%\malang-pet\malang-save.json`
