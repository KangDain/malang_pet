# malang_pet — 말랑이 키우기

배경화면에 귀여운 캐릭터들이 오버레이로 다마고치처럼 움직이는 프로그램.

다마고치처럼 하찮고 말랑한 도트 "말랑이"를 키우는 Windows 바탕화면 펫이에요 (Electron).
말랑이들은 작업표시줄 위를 폴짝폴짝 돌아다니고, 말랑이가 없는 곳은 클릭이 그대로 바탕화면으로 통과해서 평소 작업을 방해하지 않아요.
친구 코드로 연결하고 카톡처럼 **단톡방**에 모이면, 서로의 바탕화면에 말랑이가 놀러 가서 말·사진을 말풍선으로 전해 줘요.

현재 버전: **1.5.0**

## 설치 · 실행

### 그냥 쓰기 (친구에게 보낼 때도 이것)

친구에게는 **`MalangPet-Setup-1.5.0.exe` 파일 하나만** 보내면 돼요. 저장소의 `release/` 폴더에 있고, `npm run dist`로 만들면 `dist/` 폴더에도 생겨요.

| 파일 | 설명 |
| --- | --- |
| `MalangPet-Setup-<버전>.exe` | **설치판 (추천, 약 110MB).** 더블클릭하면 바로 설치되고 실행돼요. 바탕화면과 시작 메뉴에 `말랑이 키우기` 아이콘이 생겨요. 새 버전도 이 파일을 다시 실행하면 덮어써서 업데이트돼요 (키우던 말랑이는 그대로). |
| `MalangPet-<버전>.exe` | 설치 없는 단일 실행 파일 (약 100MB). 켤 때마다 압축을 풀어서 몇 초 걸려요. 저장소에는 올리지 않아요. |

- 처음 실행할 때 파란 **"Windows의 PC 보호"** 창이 뜨면 **추가 정보 → 실행**을 누르세요. 서명 인증서가 없는 개인 프로그램이라 뜨는 경고예요.
- 지우려면 Windows 설정 → 앱에서 `malang-pet`을 제거하면 돼요.
- 친구 기능을 쓰려면 **모두 같은 버전**이어야 해요 (1.5.0부터 단톡방 — 1.4 이하와는 대화·파티가 안 돼요).
- 용량 대부분은 Electron(크롬 엔진) 자체예요. 말랑이 코드·그림은 1MB 정도이고, 설치판은 최대 압축 + 한국어·영어 언어 파일만 넣어서 줄였어요.

### 소스로 실행 (개발)

```
npm install
npm start
```

### exe 만들기

```
npm run dist
```

설치판(NSIS)과 단일 실행 파일(portable)이 `dist` 폴더에 함께 만들어져요. 코드 서명은 하지 않아요.

### 켜기 · 끄기

- **켜기**: 바탕화면의 `말랑이 키우기` 아이콘. 이미 켜져 있는데 또 누르면 숨겨 둔 말랑이들이 다시 나타나요 (두 번 켜지지 않아요).
- **끄기**: 집 창의 `끄기` 버튼(한 번 더 눌러 확인) 또는 트레이 메뉴의 `종료`.
- **윈도우 켤 때 같이 켜기**: 트레이 메뉴에서 체크 (설치판/exe로 실행했을 때만 보여요).

## 화면 구성

- **말랑이** — 작업표시줄 바로 위 바닥을 돌아다녀요. 한 사람당 최대 2마리 (예전 세이브에 더 있으면 그대로 두고, 새로 입양만 막혀요).
- **말랑이네 표지** — 새싹이 든 작은 네모 말풍선 (기본 위치: 오른쪽 아래). 누르면 집 창이 열려요. 집 안에 자는 말랑이가 있으면 옆에 `z`가 떠요.
- **돌봄 카드** — 말랑이를 누르면 머리 위에 떠요. 이름 · 단계/형태 · 나이 · 상태, 배부름/기분/청결/기운 게이지, 밥 / 놀기 / 씻기 / 재우기(깨우기) / 약 버튼.
- **집 창** — 방 안 모습, 창밖 날씨, 각종 버튼. 제목줄 오른쪽에 표지 고정(자물쇠) · 표지 숨기기(눈) 아이콘.
- **친구 창** — 내 친구 코드, 친구 목록, 단톡방(모인 사람 · 받은 초대), 대화창.
- **말풍선**
  - 구름 말풍선 + 아이콘: 감정 (하트, 음표, 땀방울 등)
  - 네모 말풍선: 원하는 것 ("배고파..", "씻겨 줘!", "응가 치워 줘!")이나 쪽지 내용. 길면 여러 줄로 감싸져요.
- 테마: 시스템 / 라이트 / 다크 (집 창의 테마 버튼 또는 트레이 메뉴).

## 돌보기

| 하는 법 | 효과 |
| --- | --- |
| **말랑이 클릭** | 말랑! 하고 눌리면서 하트. 기분 조금 오름. 돌봄 카드가 열림 |
| **드래그해서 던지기** | 들었다 놓으면 통통 튀어요. 너무 세게 던지면 어지러워해요(기분 ↓) |
| **밥** | 위에서 음식 15가지 중 하나가 떨어지고 오물오물 (아래 [음식](#음식) 표). 먹으면서 흘려서 청결 −3. 배부른데 또 주면 "배불러.." |
| **놀기** | 공놀이 시작 (아래 [공놀이](#말랑이끼리--공놀이) 참고). 아프거나 너무 피곤하면 못 놀아요 |
| **씻기** | 청결 100, 비눗방울. 바닥의 응가는 빗자루가 하나씩 쓸어 가요 |
| **재우기 / 깨우기** | 재우면 집으로 걸어 들어가 침대에서 자요. 기운이 85 넘으면 "아직 졸리지 않대요" |
| **약** | 아플 때만. 다 나아요 (기분은 조금 ↓) |
| **응가 클릭** | 빗자루가 위에서 내려와 좌우로 슥슥 세 번 쓸고, 응가는 들썩이다 깜빡이며 사라져요. 청결 +5 |
| **문질문질** | 꼬질한 말랑이 위에서 마우스를 **좌우로 왔다 갔다** 하면 비눗방울과 함께 청결이 올라가요 ("간질간질", "시원해~"). 다 씻기면 반짝 |

### 꼬질꼬질 (청결)

청결이 낮아질수록 겉모습이 바뀌어요.

| 청결 | 모습 |
| --- | --- |
| 50 미만 | 몸에 얼룩 2개 |
| 30 미만 | 얼룩 4개, 냄새(구불구불 선)가 피어오름, 착지할 때 먼지가 폴폴. "꼬질꼬질해..", "문질문질 해 줘" |
| 15 미만 | 얼룩 6개, 몸빛이 탁해지고, 파리 두 마리가 맴돌아요 |

- 꼬질한 말랑이와 부딪힌 깨끗한 말랑이는 "으, 냄새..", "씻고 와~" 하며 피해요.
- 응가가 쌓여 있으면 청결과 기분이 계속 떨어져요 (최대 5개).

### 아픔

배부름이나 청결이 10 아래인 상태가 1.5시간 넘게 이어지면 아파요. 눈이 `x x`가 되고 몸이 회색이 돼요. 아프면 배고픔·심심함이 1.5배 빨리 오고, 놀 수 없어요. 약을 주면 나아요.

## 성장과 진화

| 단계 | 언제 |
| --- | --- |
| 알 | 입양 직후. 30초 뒤 깨어나요 (끝나갈수록 덜덜) |
| 아기 | 태어나서 1일까지 |
| 어린이 | 1일 ~ 3일 |
| 어른 | 3일부터. **어른이 될 때 그동안 받은 돌봄에 따라 모습이 갈라져요** |

### 어른 형태 (진화 갈래)

| 형태 | 조건 | 모습 |
| --- | --- | --- |
| **으뜸이** | 한 번도 안 아팠고, 밥·놀기·씻기를 각각 5번 이상 | 왕관 |
| **통통이** | 밥을 가장 많이 받음 | 옆으로 통통 |
| **날쌘이** | 놀기를 가장 많이 받음 | 길쭉, 점프가 높음 |
| **반짝이** | 씻기를 가장 많이 받음 | 광택이 많고 가끔 반짝반짝 |
| **느긋이** | 재우기를 가장 많이 받음 (돌봄이 하나도 없을 때도) | 납작, 느릿느릿 |
| **꼬질이** | 아기·어린이 때 꼬질한 채(청결 30 아래)로 모두 8시간 넘게 지냄 | 씻겨도 얼룩 두 점이 남음 |

- 꼬질이는 씻겨도 1.5배 빨리 다시 꼬질해지지만, 꼬질한 걸 좋아해서 그걸로는 아프지도 시무룩해지지도 않아요.

### 특성: 낚시꾼

- 집중 모드 낚시로 **물고기를 모두 100마리** 낚으면 어른 모습과 상관없이 `낚시꾼` 특성이 생겨요 (아기·어린이도). 집중 모드를 끝낼 때 `낚시꾼까지 N마리`가 보여요.
- 낚시꾼은 머리에 **밀짚모자**를 쓰고 (으뜸이는 왕관 그대로), 돌봄 카드에 `· 낚시꾼`이 붙어요.
- 입질이 더 빨리 오고 (12~25초 → 8~16초), 큰 물고기가 두 배로 잘 걸리고 쓰레기는 절반만 걸려요. 모험에서도 물고기를 1.5배 잘 잡아요.

- 어른이 되기 전에도 한 가지 돌봄을 3번 이상 받으면 카드에 **성향**이 보여요: 먹보 / 개구쟁이 / 깔끔쟁이 / 잠꾸러기. 꼬질하게 4시간 넘게 지내면 **꼬질쟁이**로 보여요 (꼬질이가 될 낌새).
- 공을 찰 때마다 놀기 돌봄이 0.25씩, 문질러서 다 씻기면 씻기 돌봄이 1 쌓여요.

### 꾸미기

- **이름**: 입양/수정 창에서. `추천` 버튼은 말랑이·모찌·푸딩·콩떡 같은 이름을 골라 줘요. 입양 창은 **제목 줄을 끌어서** 옮길 수 있고, 다음에 열 때도 그 자리에 떠요.
- **새싹 모양**: 떡잎 / 외잎 / 꽃봉오리.
- **색깔**: 기본, 딸기, 귤, 바나나, 민트, 소다, 포도, 무지개(줄무늬 고정), 무지갯빛(은은하게 색이 돌아요) + 직접 고르기. 견본이 그 색의 아기 말랑이 모양이고, 몸 색에 맞춰 새싹과 아래쪽 그림자 색도 같은 계열로 바뀌어요.
- **작별하기**: 정보 창에서 두 번 눌러야 해요.

## 하루의 흐름 (낮 · 밤 · 잠)

- **밤 (22시 ~ 6시)**: 기운이 1.6배 빨리 닳고, 가끔 "하암..", "밤이 깊었네". 기운이 50 아래면 스르르 잠들어요 (방금 깨웠다면 30분은 봐줘요).
- **아침 (6시 ~ 10시)**: 기운이 70 넘게 찼으면 기지개를 쭉 켜며 일어나서 "좋은 아침!".
- 밤에는 기운이 다 차도 아침까지 자요.
- 기운이 0이 되면 지쳐서 잠들어요.
- **컨디션이 나쁘면 알아서 쉬러 가요**: 기운 20 미만, 아픔, 또는 네 스탯 평균이 25 미만이면 "컨디션이 안 좋아서 쉬러 들어갔어요" (알림도 와요).
- **깨우면 꼭 일어나요.** 일어나자마자 필요한 걸 말풍선으로 요구해요 ("배고파.. 밥 줘!", "씻겨 줘!", "아파.. 약 줘", "심심해.. 놀아 줘!", "졸려.. 재워 줘"). 필요한 게 없으면 "잘 잤다!". 깨운 뒤 20분은 다시 쉬러 가지 않아요.

### 잠 = 집에 들어가기

1. 잠들면 졸린 눈으로 비척비척 **말랑이네 표지 아래(현관)** 로 걸어가요. 표지를 숨겼으면 오른쪽 아래 구석으로.
2. 현관에 닿으면 깜빡깜빡하다 쏙 들어가요. 표지 옆에 `z`가 뜨고, 표지에 마우스를 올리면 `쿨쿨 N`이 보여요.
3. 집 창 안에서는 **침대에 나란히 누워 이불을 덮고** 자요 (눈만 빼꼼).
4. **깨우기**: 말랑이네를 열고 침대의 말랑이를 누르면 집 창 옆에 돌봄 카드가 떠요 → `깨우기`. 현관에서 폴짝 튀어나와요.

- 한 마리를 재우면 졸린 말랑이들(기운 60 미만)이 "나도 졸려.." 하며 같이 자러 들어가요.
- 다른 말랑이와 같이 자면 기운이 1.3배 빨리 차고 외롭지 않아요(기분이 안 떨어져요).
- 처음 집에 들어갈 때 깨우는 방법을 알려 줘요.

## 말랑이네 (집)

### 집 창

- **방**: 벽지, 나무 바닥, 화분, 밥그릇, 침대(머리판·베개·이불). 깨어 있는 말랑이들은 방 안에서도 폴짝폴짝, 자는 말랑이는 침대에. 방 말랑이를 누르면 말랑.
- **창문**: 시간대와 실제 날씨, 오늘 밤 달이 보여요 (아래).
- **날씨 한 줄**: `서울 · 구름 조금 14° · 오늘 밤 보름달` + `지역` 버튼.
- **버튼**: 입양 / 모두 부르기 / 테마, 친구 · 쪽지 / 집중 모드, 모험 · 요리 / 끄기.
- **제목줄 아이콘** (닫기 왼쪽): 🔒 표지 고정 — 고정하면 잠긴 자물쇠에 바탕이 깔려요 · 👁 표지 숨기기 — 숨기면 빗금 그은 눈. 마우스를 올리면 누르면 할 일이 떠요.
- 제목줄을 끌어서 창을 옮길 수 있어요.

### 창밖

- **달**: 실제 날짜로 계산한 오늘의 달 모양을 그려요 (삭 · 초승달 · 상현달 · 차오르는 달 · 보름달 · 기우는 달 · 하현달 · 그믐달). 북반구 기준이라 차오를 땐 오른쪽부터 밝아요.
- 밤과 저녁에는 방이 어둑해지고(창문만 빼고), 비 오는 날도 살짝 어두워요. 창 양옆엔 끈으로 묶은 커튼.
- 날씨는 [Open-Meteo](https://open-meteo.com)에서 30분마다 받아 와요 (키 필요 없음). 인터넷이 없으면 맑은 하늘로 보이고 "날씨를 못 불러왔어요".
- **지역 바꾸기**: `지역` → 도시 이름 입력 (예: 부산, 수원, Tokyo). "부산"처럼 짧게 써도 `부산광역시`를 찾도록 `시 / 광역시 / 특별시`를 붙여서도 찾아보고 인구가 가장 많은 곳을 골라요. 기본은 서울.

### 표지

- **위치 옮기기**: 집 창 제목줄의 자물쇠 아이콘으로 고정을 풀면 표지를 끌어서 아무 데나 둘 수 있어요 (화면 비율로 저장돼서 해상도가 바뀌어도 그 자리).
- **고정**: 고정하면 클릭만 돼요 (마우스를 올리면 `말랑이네 · 고정됨`).
- **숨기기**: 집 창 제목줄의 눈 아이콘. 표지를 숨기면 집 창은 오른쪽 아래에서 열리고, 현관도 오른쪽 아래 구석이 돼요. 트레이 메뉴에서 다시 보이게 할 수 있어요.
- **처음 위치로**: 트레이 메뉴 → 말랑이네 표지 → 처음 위치로.
- **모두 부르기**: 깨어 있는 말랑이들이 표지 아래로 폴짝폴짝 모여요.

## 말랑이끼리 · 공놀이

- **부딪히기**: 말랑이끼리 부딪히면 통 튕겨요. 둘 다 기분이 괜찮으면 하트를 주고받아요(기분 ↑).
- **놀러 가기 (말랑이끼리)**: 20~40초마다 한 마리가 다른 말랑이에게 찾아가서 인사해요. 상대가 자고 있으면 "쉿.. 자고 있네".
- **공놀이** (`놀기`): 공이 떨어지고 20초 동안 말랑이들이 공을 쫓아다니며 톡톡 차요. 공을 마우스로 잡아 던져 줄 수도 있어요. 끝나갈 때 공이 깜빡이고, 끝나면 "모두 N번 찼어요". 놀러 온 친구네 말랑이도 같이 놀아요.

## 친구 · 쪽지 (P2P)

### 연결

1. 집 창의 `친구 · 쪽지` (또는 트레이 메뉴) → 친구 창.
2. **내 친구 코드** (`ABCD-1234` 꼴, 헷갈리는 0/O·1/I는 안 써요)를 `복사`해서 친구에게 알려 주세요.
3. 받은 코드를 `친구 추가`에 넣으면 끝. **한쪽만 추가해도 양쪽 다 친구가 돼요.**
4. `내 이름`을 적어 두면 상대 화면에 그 이름으로 보여요.

- 친구 목록: 초록 점 = 접속 중, `집중 중` = 친구가 집중 모드, `꺼져 있음`.
- 친구는 최대 20명. `삭제`(두 번 눌러 확인)하면 그 코드는 다시 연결해 와도 받지 않아요 (코드를 다시 추가하면 풀려요).
- 30초마다 꺼져 있던 친구에게 다시 연결해 봐요.

### 단톡방 — 모이면 화면이 이어져요

- **온라인 = 앱이 켜져 있는 것.** 말랑이가 자러 들어가도 오프라인이 되지 않아요. 친구 목록엔 `접속 중 · 쿨쿨`.
- **오프라인**: 앱을 끄면(집 창 `끄기`, 트레이 `종료`) 친구에게 작별 인사를 보내서 바로 `꺼져 있음`이 돼요. 컴퓨터가 꺼지거나 인터넷이 끊기면 10초마다 오가던 신호가 45초 동안 없을 때 오프라인으로 바뀌어요.
- **카톡 단톡방처럼**: 친구 창에서 친구를 고르고 `부르기` → 내가 방장인 단톡방이 생기고 친구가 바로 들어와요. 더 부르면 여럿이 모여요 (방장 포함 최대 5명).
  - 이미 다른 방에 있는 친구에게는 `○○님의 단톡방 초대 · N명 [참가]`가 떠요. 참가하면 원래 방에서는 나와요.
  - 방원끼리는 서로 친구가 아니어도 돼요. 방장이 명단과 말을 나눠 줘요. 그래서 친구를 부를 수 있는 건 방장뿐이에요.
- **화면이 이어져요**: 방에 모인 사람마다 대표 말랑이 한 마리가 내 바탕화면에 톡 떨어져서, 방에서 나갈 때까지 머물러요. 대표 말랑이 = 지금 고른 말랑이가 깨어 있으면 그 아이, 아니면 깨어 있는 첫째.
  - 놀러 온 말랑이도 내 말랑이들과 부딪히고 하트를 주고받고 공놀이를 해요. 마우스를 올리면 `○○의 콩떡`, 누르면 인사하고 친구 창이 열려요. 끌어서 옮기거나 던질 수도 있어요.
- 친구 창 아래에 방 사람들(`방장` · `집중 중` · `쿨쿨`)과 `나가기`. **방장이 나가면 방이 닫혀요** (방장이 말을 전해 주기 때문). 방장이 앱을 꺼도 닫혀요.
- **내보내기**: 방장은 사람마다 `내보내기`(두 번 눌러 확인). 내보내진 사람 화면에서는 방이 닫히고 다른 사람들 화면에서는 그 말랑이가 돌아가요. 방장이 다시 부르면 들어올 수 있어요.

### 단톡방 대화 · 말풍선

- 단톡방에 있을 때 쪽지(최대 40자)를 쓰고 `보내기` (Enter도 돼요) → 방 사람 모두에게. 방에 없으면 입력칸이 잠겨요.
- **내 화면에서는 내 대표 말랑이가, 다른 사람 화면에서는 그 화면에 놀러 가 있는 내 말랑이가** 그 말을 말풍선으로 말해요. 말랑이가 다 자고 있으면 말랑이네 표지 위에 떠요.
- 집중 모드 중이면 `집중 중` 말풍선이 맨 아래에 있고, 쪽지 말풍선은 그 위로 쌓여요.
- **말풍선 쌓기**: 새 쪽지는 머리 바로 위에, 예전 쪽지는 위로 밀려 올라가며 흐려져요 (최신 · 50% · 28%, 최대 3개). 하나씩 20초 뒤에 스르르 사라져요.
- **대화창**: 친구 창 안에 내가 보낸 말은 오른쪽(초록), 다른 사람 말은 왼쪽 말풍선으로 쌓여요. 셋 이상 모이면 누가 한 말인지 이름이 붙고, 들어오고 나간 것도 보여요. 사진도 함께 보여요. (대화 기록은 앱을 끄면 사라져요.)

### 사진

- 📷 버튼으로 고르거나, 캡처한 이미지를 쪽지 칸에 **붙여넣기(Ctrl+V)** 하면 첨부돼요. `빼기`로 취소.
- 사진은 JPEG로 줄여서(긴 변 최대 400px, 100KB 이하) 보내요. 받는 쪽에서는 말랑이 머리 위에 폴라로이드로 떠요.

### 흔들기

- `흔들기`를 누르면 친구 화면의 말랑이들이 크게 덜덜 떨면서 폴짝 튀어 올라 `!`. 자고 있으면 말랑이네 표지가 들썩여요. 내 화면에 놀러 와 있는 친구네 말랑이도 같이 흔들려요.
- **20초 안에 3번 넘게 흔들리면 어질어질**: 눈이 빙글빙글(`@ @`) 돌고, 머리 위로 별이 돌고, 7초 동안 비틀비틀 휘청거려요 ("어질어질..", "헤롱헤롱~").
- 친구가 집중 모드이거나 말랑이가 자고 있어도 흔들 수 있어요. 3초에 한 번까지.

### 알아 둘 것

- **둘 다 켜져 있을 때만** 전해져요. 서버에 쪽지를 저장하지 않아요.
- 공개 PeerJS 서버(`0.peerjs.com`)는 둘을 이어 줄 때만 쓰고, 쪽지·사진은 둘 사이(WebRTC)로 바로 오가요.
- 회사·학교처럼 막힌 네트워크에서는 연결이 안 될 수 있어요. (서로의 인터넷 주소를 찾는 STUN은 잘 열려 있는 3478 포트 서버를 먼저 써요. 그래도 PC끼리 바로 못 이어지는 망에서는 중계 TURN 서버가 있어야 하는데 아직 없어요.)
- 친구 코드를 아는 사람은 누구나 연결할 수 있으니 아는 사람에게만 알려 주세요.

## 모험 · 요리 (방치형 RPG)

집 창의 `모험 · 요리` 버튼으로 **화면 왼쪽 아래 작은 모험 창**을 열어요 (제목줄을 끌어 옮길 수 있어요, 닫아도 모험은 계속).

### 모험 보내기

- 보낼 말랑이와 갈 곳을 고르고 `혼자 출발`. 말랑이는 바탕화면에서 사라져 모험 창 안에서 걸어가며 **30초마다 한 번씩 알아서 싸워요**.
- 싸우는 모습: 몬스터가 다가오고, 서로 콩콩 부딪히며 숫자가 톡톡 뜨고, 이기면 펑 연기와 함께 재료가 `+1`로 떠올라요.
- **앱이 꺼져 있던 동안의 싸움도** 켤 때 한꺼번에 계산해요 (12시간까지). "자리를 비운 동안 모찌가 84마리를 물리쳤어요".
- 이렇게 되면 알아서 돌아와요: 체력 0 (쓰러짐, 기분 −10) · 체력 20% 아래 · 배부름 15 아래 · 기운 15 아래. `돌아오기`로 언제든 불러요. 돌아오면 현관에서 폴짝, 체력은 다시 꽉.
- 갈 수 없을 때: 알 · 자는 중 · 아픔 · 배부름 30 아래 · 기운 30 아래.

| 지역 | 레벨 | 몬스터 | 재료 | 보스 (파티) |
|---|---|---|---|---|
| 풀숲 | 1 | 들쥐 · 무당벌레 | 밀 · 베리 | 들쥐 대장 |
| 버섯 숲 | 4 | 버섯돌이 · 꿀벌 | 버섯 · 꿀 · 베리 | 버섯왕 |
| 들판 목장 | 7 | 꼬꼬 · 얼룩소 | 달걀 · 우유 · 밀 | 화난 황소 |
| 바닷가 | 10 | 꽃게 · 해파리 | 생선 · 베리 | 대왕 꽃게 |
| 반짝 동굴 | 14 | 박쥐 · 두더지 | 감자 · 꿀 | 돌골렘 |

### 레벨 · 능력치

- 이기면 경험치 → 레벨 업 (체력 꽉). 체력 `30 + 9×레벨`, 공격 `4 + 2.2×레벨`. 돌봄 카드에 `Lv.N`.
- 어른 모습마다 특기: 통통이 체력 +20% · 날쌘이 공격 +15% · 반짝이 재료 +30% · 느긋이 덜 지침 · 으뜸이 모두 +10% · 꼬질이 체력 +10%·재료 +20%.
- 모험하면 배부름 시간당 −18, 기운 −15. 싸움 사이사이 체력이 조금씩 차요.

### 탐험 · 장비 · 옷장

- **탐험**: 한 지역에서 30마리를 물리치면 그 지역 `탐험 끝`. 모험 창의 지역 버튼에 `12/30`처럼 진행이 보여요. 예전부터 키운 말랑이는 레벨로 보아 이미 지나온 지역을 탐험한 걸로 쳐요.
- **장비 줍기**: 이긴 싸움마다 가끔(보스는 자주) 그 지역 장비를 주워 와서 옷장에 넣어요. 같은 장비는 식구 수만큼까지만 모여요. 처음엔 연습용 `나무 칼` · `나무 활`이 하나씩 있어요.
- **입는 조건**: 레벨 + 앞 지역 탐험. 조건이 모자라면 옷장 목록에 빨간 글씨로 보여요.
- **옷장**: 집 창 `옷장` 버튼이나 방 안 옷장을 누르면 열려요. 말랑이를 골라 `입히기` / `벗기기`. 위쪽 장면에서 문 열린 옷장과 입은 모습을 볼 수 있어요. 모험 간 아이는 돌아오면 갈아입힐 수 있어요.
- 입은 갑옷은 몸 아래쪽 띠로, 무기는 옆구리에 들고 있는 모습으로 바탕화면 · 집 · 모험 창 어디서나 보여요. 활을 든 아이는 모험에서 제자리에서 화살을 쏴요.
- 친구 화면에도 각자 입은 장비와 낚시꾼 모자가 보여요 (단톡방 손님 말랑이 · 모험 파티원). 갈아입으면 친구 화면에도 몇 초 안에 바뀌어요.

| 단계 | 주울 수 있는 곳 | 조건 | 칼 (공격) | 활 (공격 · 받는 피해 −15%) | 갑옷 (체력 · 받는 피해) |
| --- | --- | --- | --- | --- | --- |
| 나무 | 풀숲 | Lv.1 | 나무 칼 +3 | 나무 활 +2 | 나뭇잎 옷 +4 · −5% |
| 돌 | 버섯 숲 | Lv.4 · 풀숲 탐험 | 돌 칼 +5 | 덩굴 활 +4 | 버섯 갑옷 +8 · −8% |
| 쇠 | 들판 목장 | Lv.7 · 버섯 숲 탐험 | 쇠 칼 +8 | 깃털 활 +6 | 가죽 갑옷 +14 · −11% |
| 산호 | 바닷가 | Lv.10 · 들판 목장 탐험 | 산호 칼 +11 | 조개 활 +8 | 조개 갑옷 +20 · −14% |
| 수정 | 반짝 동굴 | Lv.14 · 바닷가 탐험 | 수정 칼 +14 | 수정 활 +10 | 수정 갑옷 +28 · −17% |
| 별빛 | 반짝 동굴 (아주 드물게) | Lv.18 · 반짝 동굴 탐험 | 별빛 칼 +18 | 별빛 활 +13 | 별빛 갑옷 +36 · −20% |

### 요리

- 모험 창 `요리` 탭: 가방(모아 온 재료, **연못에서 낚은 물고기도** 들어와요) → 레시피 `만들기` → 만든 요리 `먹이기`.
- 요리 탭 위쪽은 **주방 도트 장면** (창문 · 잼병 선반 · 타일 벽 · 국자 · 가스레인지). 집에 있는 깨어 있는 아이가 `○○네 주방`의 요리사예요. `만들기`를 누르면 재료가 하나씩 팬으로 퐁퐁 → 불이 붙고 뒤집개로 휘휘, 김이 모락모락 → 팬 위로 요리가 쏙, 반짝이와 `○○ 완성!` (약 3.6초).
- 먹이면 밥처럼 위에서 톡 떨어져 먹고, **버프가 1시간** 붙어요. 모험 중이면 `도시락`으로 그 아이에게 바로 보내요 (배부름이 차서 모험을 더 오래 해요).

| 요리 | 재료 | 효과 |
|---|---|---|
| 빵 | 밀 2 | 배부름 +28 |
| 베리 파이 | 밀 1 · 베리 2 | 공격 +25% |
| 달걀프라이 | 달걀 1 | 배부름 +26 |
| 버섯 수프 | 버섯 2 · 우유 1 | 받는 피해 −30% |
| 생선구이 | 생선 1 | 경험치 +30% |
| 감자구이 | 감자 2 | 배고픔·기운 덜 닳음 |
| 꿀 케이크 | 밀 2 · 달걀 1 · 꿀 1 | 재료 +50% |
| 팬케이크 | 밀 1 · 달걀 1 · 우유 1 · 꿀 1 | 모든 능력 +15% |

### 친구랑 파티 (최대 5명)

- 친구들과 **단톡방에 모여 있을 때** `같이 가자고 하기` → 방장이 파티를 열고, 방 사람 모두의 모험 창에 `○○님 파티 · 풀숲 · N명 [참가]`가 떠요. 각자 자기 말랑이를 골라 참가.
- 모험 창에 파티원 말랑이들이 줄지어 같이 싸우고, 파티원 이름 · 레벨 · 체력 막대가 보여요.
- 파티 보너스: 한 명마다 경험치·재료 +20%. 공격은 다 같이 더해서 때려요.
- **여덟 번째 싸움마다 보스** (왕관): 체력이 인원수만큼 크고, 맞는 피해는 나눠 받아요. 재료를 많이 줘요.
- 파티장은 방장 — 방원끼리는 직접 이어져 있지 않을 수 있어서 방장이 파티원 소식을 모아 5초마다 나눠 줘요. 연결이 끊긴 동안·앱을 끈 동안은 혼자 싸워요 (보너스 없음).
- 아무나 `돌아오기` 하면 그 아이만 빠지고, 다른 파티원은 계속 싸워요.

## 편의 기능

### 집중 모드

- 집 창의 `집중 모드` 버튼 또는 트레이 메뉴에서 켜고 꺼요 (켜져 있으면 버튼이 초록, `집중 끝내기`).
- **✏ 집중 중 말풍선이 끌 때까지 계속** 떠 있어요. 감정 구름이나 다른 말보다 우선이고, 쪽지 말풍선은 그 위로 쌓여요. 다들 자고 있으면 말랑이네 표지 위에.
- **단톡방 사람들 화면에서도** 놀러 가 있는 내 말랑이 위에 `집중 중` 말풍선이 떠요. 친구 목록 · 단톡방 명단에도 `집중 중`.
- 말랑이들이 혼잣말(하품, 기분 구름)을 멈춰요.
- 집중 중에도 단톡방 대화는 돼요. 흔들기만 막혀요.
- 모험 중에 집중하면 경험치·재료가 50% 더 (모험 보낸 아이만 있어도 집중 모드는 계속돼요).

#### 다른 프로그램을 절대 방해하지 않아요

집중하는 동안 말랑이는 **보이기만 하고 손대지 않아요.**

| 무엇을 | 집중 중에는 |
| --- | --- |
| 마우스 | 말랑이 · 놀러 온 친구 말랑이 · 공 · 응가 위를 눌러도 **밑에 있는 프로그램이 그대로 눌려요.** 말랑이를 집거나 카드를 열 수 없어요. 누를 수 있는 건 말랑이네 표지와 직접 열어 둔 창(집 · 친구 · 모험)뿐. |
| 키보드 | 말랑이를 잘못 눌러 말랑이 창이 앞으로 나오면서 쓰던 프로그램의 입력을 뺏는 일이 없어요 (위와 같은 이유). |
| 자리 | 말랑이들과 놀러 온 친구 말랑이들이 **오른쪽 아래 연못 근처 구석에서만** 놀아요. 다른 데 있던 아이도 집중을 켜면 폴짝폴짝 구석으로 와요. |
| 알림 글 | 화면 가운데 아래 대신 **오른쪽 구석**에 떠요 (원래 클릭은 통과). |
| 윈도우 알림 | 하나도 띄우지 않아요 (단톡방 말 · 흔들기 · 배고픔 · 모험에서 돌아옴 전부). |
| 창 띄우기 | 단톡방에서 "같이 모험 가자"고 해도 모험 창을 저절로 열지 않고 알림 글만. |
| CPU · GPU | 화면을 1초에 60번 → **30번**만 그려요. |

- 말랑이와 놀고 싶으면 집중 모드를 끄면 바로 원래대로 돌아와요.
- 크롬 같은 프로그램이 멈추던 문제는 집중 모드와 상관없이 고쳐져 있어요 (아래 기술 메모의 **창**).

#### 연못 낚시

- 집중 모드를 켜면 대표 말랑이가 **오른쪽 아래 구석의 작은 연못**(연잎·부들)으로 폴짝폴짝 걸어가서 낚싯대를 드리워요.
- 찌가 둥실둥실 떠 있다가 12~25초마다 **입질**: 찌가 쏙쏙 들어가고 `!` → 휙 낚아 올려요 (물방울이 튀고 말랑이가 폴짝).
- 걸린 건 낚싯줄 끝에 대롱대롱 매달려 잠깐 자랑해요.
  - **물고기** (작은 물고기, 가끔 큰 분홍 물고기): 하트, 기분 +3 — 모험 가방에 생선으로 들어가요
  - **쓰레기** (장화, 깡통): 시무룩, 기분 −1
- 집중 모드를 끄면 "그동안 물고기 3마리, 쓰레기 1개를 낚았어요".
- 낚시하는 말랑이는 다른 말랑이와 부딪히거나 놀러 가지 않아요. 들어서 옮기면 다시 연못으로 걸어가요.
- **연못은 누군가 낚시하러 가 있을 때만** 보여요.
  - 낚시하던 아이가 잠들면 깨어 있는 다른 아이가 이어서 낚시해요.
  - **이어서 할 아이가 없으면 집중 모드가 저절로 끝나고 연못도 바로 사라져요** ("솜사탕이 잠들어서 집중 모드를 끝냈어요" + 낚은 것).
  - 낚시하던 아이를 모험 보내고 남은 아이가 없으면 집중 모드는 그대로, 연못만 사라져요.
- 🎣 **같이 낚시 (최대 5명)**: 단톡방에 모인 친구가 **같이 집중 모드**면, 내 화면에 와 있는 그 친구 말랑이도 연못 둘레에 자리를 잡고 같이 낚시해요 ("○○님도 집중 중! 같이 낚시해요"). 왼쪽·오른쪽 번갈아 서고 둘째 줄부터는 한 칸씩 뒤에서 더 긴 낚싯대로. 누가 물고기를 낚으면 나머지가 음표를 띄우며 박수쳐요.

### 방해 금지 모드

- 게임·영상처럼 **전체화면 창이 앞에 있으면 말랑이를 잠깐 숨겨요.** 전체화면이 끝나면 다시 나타나요. 숨은 동안엔 알림도 쉿.
- 트레이 메뉴 → `방해 금지 모드 (전체화면일 때 숨기기)` (기본 켜짐).
- 1.5초마다 맨 앞 창이 모니터 전체를 덮는지 확인해요 (PowerShell + user32, 별도 모듈 없음). 바탕화면·작업표시줄은 제외.

### 알림

- 트레이로 숨겨 뒀을 때 배고픔·심심함·더러움·졸림이 20 아래로 떨어지거나, 아프거나, 지쳐 잠들면 윈도우 알림이 와요. **집중 모드 · 방해 금지 중엔 오지 않아요.**
- 프로그램을 꺼 둔 동안에도 시간은 흘러요. 다시 켜면 그동안의 변화가 한꺼번에 반영되고 "자리를 비운 동안 N시간이 흘렀어요".

## 프로젝트 구조 · 기술 메모

```
main.js               Electron 메인: 투명 전체화면 창, 클릭 통과, 트레이, 저장, 방해 금지(전체화면 감시)
preload.js            렌더러에 window.malang API (저장/불러오기, 클릭 통과, 트레이, 설정, 끄기)
index.html            돌봄 카드 · 집 창 · 친구 창 · 입양 창 마크업 (CSP 포함)
style.css             픽셀 상자/버튼, 대화창 등
renderer.js           게임 전부: 시뮬레이션, 도트 그리기, 말랑이 움직임, 집, 날씨, 친구(P2P)
rpg.js                모험 · 요리 · 파티 (renderer.js 다음에 읽혀서 hooks로 끼어들어요)
vendor/peerjs.min.js  PeerJS 1.5.4 (P2P 연결)
fonts/                갈무리 픽셀 폰트
build/icon.png        앱 아이콘
color.txt.txt         라이트/다크 팔레트 원본
```

- **창**: 작업 영역 전체를 덮는 투명·테두리 없는 창. 말랑이·응가·표지·UI 위에 마우스가 있을 때만 클릭을 받고(`setIgnoreMouseEvents`), 나머지는 바탕화면으로 통과. 집중 중엔 표지·UI 위에서만 받아요.
  - **도구 창**(`type: 'toolbar'` → `WS_EX_TOOLWINDOW`)으로 만들어요. 화면 전체를 덮는 창이라, 말랑이를 눌러 클릭 통과가 잠깐 풀리면 크롬 같은 프로그램이 "다른 창에 가려졌다"고 보고 그리기를 멈췄어요. 도구 창은 그 가림 계산에서 빠져요. 그래서 Alt+Tab 목록에도 안 나와요.
  - 프레임 루프는 다음 프레임을 먼저 예약해요. 한 프레임에서 오류가 나도 앱이 굳지 않아요.
- **그리기**: 모든 캐릭터는 문자열 스프라이트(`SPR`)와 칸 단위 래스터라이저(`Cells`)로 그려요. 테두리는 자동으로 둘러져요. 말랑이 몸은 초타원 돔 + 스프링 찌그러짐.
- **저장**: `%APPDATA%\malang-pet\malang-save.json` (임시 파일에 쓰고 바꿔치기). 15초마다, 그리고 끌 때 저장. 예전 세이브는 불러올 때 새 항목을 채워 넣어요.
- **시간**: 마지막 저장 시각부터 1분 단위로 시뮬레이션을 돌려서 꺼져 있던 시간도 반영.
- **P2P**: PeerJS(공개 서버) + WebRTC 데이터 채널, JSON 메시지.
  - `hi` (코드·이름·집중 상태·대표 말랑이 모습) — 코드가 실제 연결 주소와 같은지 확인해서 남의 코드를 흉내 낼 수 없어요.
  - `part` (사진 조각), `shake`, `status` (집중 모드·다 자는 중), `ping` (10초마다, 45초 없으면 끊김), `bye` (앱을 끌 때).
  - 단톡방: `rinv` (방장 → 친구: 부르기), `rjoin` (→ 방장: 들어가기·대표 말랑이 모습), `rroster` (방장 → 모두: 명단·집중·자는지, 5초마다), `rleave`, `rkick` · `rfull` · `rgone` · `rclose` (방장 → 방원: 내보냄·꽉 참·없는 방·방 닫음).
  - `rmsg` (말·사진 번호): 방원 → 방장, 방장 → 다른 방원들(보낸 사람 코드·이름을 붙여서, 사진은 다시 조각내서). 방장 소식이 20초 끊기면 방원 쪽에서 방이 닫혀요.
  - 파티: `pask` (방원 → 방장: 같이 가자), `pinv` (방장 → 방원: 초대), `pjoin` / `pstat` (파티원 → 파티장: 레벨·체력, 싸울 때마다), `pleave`, `proster` (파티장 → 모두: 명단, 5초마다).
  - 둘이 동시에 연결을 걸어 연결이 두 개 생겨도, 인사를 마친 연결이면 어느 쪽으로 와도 받아요.
  - PeerJS JSON 채널은 한 메시지가 16KB까지라 사진은 12,000자씩 나눠 보내고, 받는 쪽에서 조각 수(10개)·크기·형식(`data:image/jpeg|png|webp;base64`)을 확인해요.
- **날씨**: Open-Meteo 예보 API(`current=temperature_2m,weather_code`) + 지오코딩 API. WMO 날씨 코드를 맑음/구름 조금/흐림/안개/비/눈/천둥번개로 묶어요.
